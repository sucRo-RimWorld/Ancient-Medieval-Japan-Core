# 七穀の環境比較回帰

2026-10-08。実装値の正本は各PlantDef、`Patches/UplandRice.xml`、および各作物のバランス資料。
陸稲統合後のGrainsでは、アワ・ヒエ・キビ・ソバ・大麦・小麦・陸稲の7作物を比較する。

| 軸 | 代表値 |
|---|---|
| 肥沃度 | 0.5 / 1.0 / 1.4 |
| 定温 | 10 / 20 / 30℃ |
| 有効成長日 | 5 / 10 / 20日 |

有効成長日は完全光量・休眠なしで成長できる時間の合計であり、暦日ではない。
種まき・収穫・加工の労働時間、初期成長、部分成熟収穫、作物間の栄養差、
播種研究の取得、天候、病害、霜、室内設備、栽培者技能・難易度は評価へ混ぜない。

計算は `floor(有効成長日 × 肥沃度係数 × 温度係数 / growDays) × harvestYield`。
肥沃度が fertilityMin 未満なら0。肥沃度係数は
`1 - fertilitySensitivity + 肥沃度 × fertilitySensitivity`。
温度係数は成長可能域から最適域へ線形に0→1、最適域で1、高温側で1→0とする。

Base小麦は明示値0/10/42/58℃、MO小麦の静的モデルは0/6/42/58℃を仮定する。
MO小麦の温度はPlantProperties既定値による静的仮定であり、Pickle側はロード済みDefと
実ゲームのPlantUtilityで別途検証する。

陸稲は `Plant_Rice` を8日・収量20・fertilityMin 0.7・fertilitySensitivity 0.9・
10～42℃（最適20～35℃）へPatchする。詳細根拠は [`UplandRice.md`](UplandRice.md)。
将来の水稲は本比較に含めない。

27セル中23セルで成熟収穫が可能。最大収量の回数（同率を両方へ算入）は
Awa 1、Hie 2、Kibi 8、Soba 4、Barley 4、Wheat 4、Upland Rice 2。

| 穀物 | 最大収量となる代表セル（肥沃度 / 温度 / 有効成長日） | 収量 |
|---|---|---:|
| アワ | 0.5 / 30℃ / 10日 | 13 |
| ヒエ | 1.4 / 20℃ / 5日 | 12 |
| キビ | 1.0 / 20℃ / 5日 | 11 |
| ソバ | 0.5 / 10℃ / 10日 | 8 |
| 大麦 | 1.0 / 10℃ / 10日 | 22 |
| 小麦 | 1.4 / 10℃ / 10日 | 28 |
| 陸稲 | 1.4 / 20℃ / 20日 | 60 |

回帰条件は全セルの成熟収量・勝者の固定、七穀それぞれの代表用途維持、
単一穀物が有効セルの2/3以上で最大にならないこと。
CCTOの枯死・耐霜差とMO Strawの価値、将来の水田投資・水稲収量は別評価とする。

実行: `python Tests/test_grains_environment.py`。
意図的に値を変更するときは設計正本・XML/Patch・回帰Fixture・説明を同時に更新し、
Fixtureだけを自動更新して失敗を消さない。
