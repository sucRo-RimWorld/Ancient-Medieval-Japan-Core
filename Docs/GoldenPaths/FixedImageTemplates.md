# AMJ 共通画像パーツ固定テンプレート運用（正本）

この文書は、**同じ可視パーツを複数画像でピクセル単位に再利用する場合だけ**適用する共通ルールの正本である。

画風の正本は `Docs/ArtStyle.md`、一般的な生成許可・素材保存・PNG検証は `Docs/GoldenPaths/TextureAssetPipeline.md`。枡やWorkshop表紙などの前後関係・レイアウト・専用マスクは各系統のGolden Pathが所有する。本書へ系統固有の失敗履歴や領域契約を複製しない。

## 適用条件

固定テンプレートを使うのは、承認済みの**同じパーツ**を再利用するときだけ。

対象例:
- 共通容器;
- Workshop表紙の共通タイトル/背景;
- 同一の道具・部材;
- 同一個体の状態差分で明示的に固定した部分。

「同じ画風」「同じカテゴリ」「別種だが似ている」は固定パーツではない。別樹種など、固有シルエットが必要な画像に不要な画素固定を課さない。

## 必須原則

- 承認済み共通パーツは生成モデルに描き直させず、登録済みマスターの画素を再利用する。
- 生成・描画対象は可変部分だけとする。
- 最終画像は決定的に合成し、保護範囲のdecoded RGBA差分を0画素にする。
- 見た目が似ている、参照画像を付けた、という理由でピクセル一致を主張しない。
- 系統固有の遮蔽・前後関係・可変領域は、その系統のGolden Pathで定義する。共通ルール側で一律の前景/後景モデルを発明しない。

## テンプレート登録

各系統の所有リポジトリに、少なくとも以下を登録する。

- 承認済み可逆PNGマスター;
- 変更可能/保護範囲を機械判定できるマスクまたは同等の領域定義;
- JSONマニフェスト:
  - family / version;
  - 寸法;
  - マスターと領域定義のパス;
  - SHA-256;
  - 可変範囲の意味;
  - 合成/検証入口;
- 必要なら、シリーズ全体の大きさ・余白・充填量・前後関係を確認する承認済み完成例。

Persistent Libraryをバイナリ正本にする場合は、Libraryの完全パス・寸法・SHA-256をマニフェストへ記録する。取得できない場合は推測や再生成で代替せずBLOCKEDとする。

マスターまたは領域契約を変更する場合は版を上げる。派生画像ごとにマスターやマスクを変更して合格させない。

## 制作と検査

1. 対象リポジトリの `AGENTS.md` と `main:Docs/Coordination.md`、本書、系統固有Golden Pathを読む。
2. 登録済みマスター/領域定義/承認参照を実際に取得し、ハッシュと寸法を確認する。
3. 可変部分だけを生成または描画する。ImageGenの使用可否は `TextureAssetPipeline.md` に従う。
4. 系統固有の compositor / script で合成する。固定パーツに拡縮・回転・色補正・ぼかし・全体量子化を適用しない。
5. 最終PNGを再デコードし、保護範囲のRGBA全4チャンネル差分が0画素であることを機械検査する。透明画素のRGBも対象とする。
6. 所有リポジトリのPNG構造/CRC/デコード検査を別途実行する。
7. 可変部分の見た目・小サイズ可読性は人間が確認する。固定画素PASSは可変部分の画風や構図の合格を意味しない。

客観的に修正可能なジャギー、ハロー、継ぎ目、切れ、残骸などは候補提示前に修正する。誤ったマスター・参照・領域定義から派生した成果物は正本候補として再利用しない。

## 共通ツール

Coreの `Scripts/Art/fixed_template.py` を共通実装として使う。系統固有の領域意味や前後関係が必要な場合は、同ツールの系統入口または所有リポジトリの専用scriptを使い、本書へその詳細を複製しない。

通常の二値マスク系統の例:

```bash
python Scripts/Art/fixed_template.py compose path/template.json path/variable.png --output path/final.png
python Scripts/Art/fixed_template.py validate path/template.json path/final.png
python Tests/test_fixed_template.py
python Tests/validate_png_assets.py
```

ツールPASSだけでテンプレートの視覚承認や系統固有条件の達成を主張しない。

## 系統別の正本

- 枡入り資源: `Docs/GoldenPaths/BoxedResourceIconPipeline.md`
- Workshop表紙: `Docs/GoldenPaths/WorkshopCoverPipeline.md`
- その他の新しい固定系統: その所有リポジトリの正式仕様/Golden Path

新しい共通パーツ系統を作る場合は、最初の派生を量産する前に登録する。共通パーツのない単独画像には本書を適用しない。
